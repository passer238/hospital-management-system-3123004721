## 项目简介

本项目是一个基于B/S架构的医院信息管理系统，采用Python Flask框架开发，使用SQL Server作为数据库。系统实现了医院门诊业务的完整流程管理，包括挂号、就诊、处方、收费、取药等核心功能。

## 技术栈

| 层次       | 技术                |
| ---------- | ------------------- |
| 数据库     | SQL Server 2019     |
| 后端       | Python 3.11 + Flask |
| 前端       | Bootstrap 5 + HTML5 |
| 数据库驱动 | pyodbc               |

## 快速开始

### 1. 环境准备

- Python 3.11+
- SQL Server 2019
- ODBC Driver 17 for SQL Server

### 2. 数据库初始化

**方式一：自动初始化**

直接运行提供的一键初始化脚本，将自动按顺序执行所有 SQL 文件。

```bash
cd src
python init_all_db.py
```

**方式二：手动初始化**

在 SQL Server Management Studio (SSMS) 中依次执行以下文件：

```sql
-- 1. 创建数据库和表
-- 执行 sql/00_建表脚本.sql

-- 2. 插入初始数据（可选）
-- 执行 sql/01_初始数据.sql

-- 3. 创建视图（可选）
-- 执行 sql/02_视图.sql

-- 4. 创建存储过程（可选）
-- 执行 sql/03_存储过程.sql

-- 5. 创建触发器（可选）
-- 执行 sql/04_触发器.sql
```

### 3. 数据维护（备份与恢复）

项目包含完整的数据库备份方案，位于 `sql/05_备份恢复方案.sql`。

- **自动备份演示**：运行 `python src/backup.py` 可执行一次完整备份（备份文件默认保存至 `D:\Backup\Hospital`）。
- **手动维护**：参考 `sql/05_备份恢复方案.sql` 中的脚本配置 SQL Server Agent 自动作业。

### 4. 安装依赖

```bash
cd src
pip install -r requirements.txt
```

### 5. 运行应用

```bash
python app.py
```

访问 http://127.0.0.1:5000

## 功能模块

| 模块     | 功能                   |
| -------- | ---------------------- |
| 挂号管理 | 挂号登记、查询、删除   |
| 医生管理 | 医生信息维护、在岗状态 |
| 病人管理 | 病人档案、病历管理     |
| 药品管理 | 药品信息、库存管理     |
| 处方管理 | 开具处方、药品添加     |
| 收费管理 | 费用计算、收费记录     |
| 支付管理 | 支付确认、取药票单     |
| 取药管理 | 取药确认               |
| 数据统计 | 营收统计、工作量分析   |

## 数据库设计

- **8个数据表**：病人、医生、药品、挂号、处方、收费、支付、取药
- **5个视图**：就诊记录、库存预警、营收统计等
- **4个存储过程**：结算处理、入库管理等
- **4个触发器**：库存扣减、完整性检查等
